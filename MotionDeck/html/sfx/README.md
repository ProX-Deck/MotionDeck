# 音效（运行期 · 丢 mp3 进来才响）

本目录是「运行期音效目录」。Studio 每张卡参数里的「音效」下拉，选中后会在卡片出现时
响一声，并自动混入导出的 MOV 音轨。

**本仓库不附带音效文件**——免费音效通常允许你用在视频作品里，但不允许把音频文件
本身当素材库再分发。所以请自己下载后放进这个目录。

## 下拉项是固定的，文件要你自己放

下拉选项写死在代码里，你得把同名 mp3 丢进这个目录，选项才真的能响；没放文件时，选项能选中但播放会 404（静默失败）。

把下面这些名字的 `.mp3` 放进本目录即可（文件名必须完全一致，含中划线）：

| 文件名            | 下拉里的选项       |
|------------------|--------------------|
| pop-light.mp3    | 轻点 pop           |
| pop.mp3          | 弹出 pop           |
| pop-cluster.mp3  | 连环 pop（多物弹入）|
| whoosh.mp3       | 大转场 嗖          |
| whoosh-soft.mp3  | 轻转场 嗖          |
| type.mp3         | 打字声             |
| click.mp3        | 点击               |
| shutter.mp3      | 相机快门           |
| chime.mp3        | 翻页 叮            |
| ding.mp3         | 达成铃             |
| impact.mp3       | 重击（盖章/落锤）  |
| hit-soft.mp3     | 轻击               |
| glitch.mp3       | 电子故障           |
| sparkle.mp3      | 魔法闪光           |
| rise.mp3         | 数字上升           |

（下拉里另有两个特殊项：空 =「自动（按特效类型）」；`无音效` = 不响。它们不需要文件。）

## 导出时怎么选音效

系统把卡片类型映射到上面的音效值（如 计数类→
`rise`、盖章类→`impact`、照片类→`shutter`、结构步骤类→`click`），默认 `pop-light`。
所以只要上面的 mp3 都备齐，「音效 = 自动」就能按卡片类型自动配对的音。

## 怎么用

1. 到免费音效站下载 mp3（如 [Mixkit](https://mixkit.co/free-sound-effects/)、
   [Freesound](https://freesound.org/)，下载前确认许可允许你的用途）。
2. 按上表命名，放进 `MotionDeck/html/sfx/`（与 `html/fonts` 并列）。
3. 在卡片参数里选「音效」，点一下即可试听（`new Audio('/sfx/<名>.mp3')`）。
4. 导出时音效自动烤进 MOV 音轨；找不到文件则跳过，成片照常输出。

## 注意
- 本目录为空不影响任何功能，只是没有音轨而已；想要音效随时再加。
