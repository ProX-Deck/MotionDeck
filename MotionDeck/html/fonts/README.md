# 字体（运行期 · 丢进来即用）

本目录是「运行期自定义字体目录」。把字体文件丢进来，刷新页面，Studio 左栏「全局字体」
下拉和字幕卡的「字幕字体」框就能选用。

## 怎么加

把 `.ttf` / `.otf` / `.woff` / `.woff2` 丢进这个目录：

- **字体名 = 文件名（去掉扩展名）**。
- 同一家族有多个字重时，文件名写成「家族名-字重数字」：

  ```
  思源黑体-400.otf
  思源黑体-700.otf
  思源黑体-900.otf
  ```

  会合并成一个下拉项「思源黑体」，各字重按真实字形渲染。不这么命名，浏览器只能用
  唯一字重「伪粗」，大标题会糊。

## 背后的机制

- 服务启动时会自动建好这个目录（`server.mjs` 的 `FONT_DIR`）。
- server 经 `GET /api/fonts` 扫描本目录、返回 `[{ family, weight, file }]` 清单，
  `/fonts/*` 提供字体文件。
  「全局字体」下拉随之刷新（运行期新增的字体，不刷新页面也会自动出现）。

## 去哪找（自行确认商用授权）

- 思源黑体（SIL OFL，可再分发）/ 站酷字体系列 / 阿里巴巴普惠体

## 注意

- 本仓库不附带字体文件：中文字体很多标「免费商用」却不允许「随软件再分发」，
  两者不是一回事，请自行下载后放入。
