## 偏好·落位（口播人像默认主轴）

继承 default 的「左右分流、不 center 盖脸」，但**默认偏左**（本期 19 张非 demo 卡中 12+ 张被往左拖，offsetX 大面积为负）：

| 卡型 / 场景 | 落位（覆盖 default） | 说明 |
|---|---|---|
| `impact-open-title` / `outline-box-title` / `keyword-pop-highlight` / `strike-and-replace` / `speed-slab-title` / `slab-punch-title` 等论点·标题·强调类 | **`left`**（不用 `center`） | 本期 card-3 从 `center` 改 `left`；center 必盖脸，标题卡一律走 left。 |
| `pin-board` 要点钉板 | **`top-left` / `left`** | 本期 card-4 从 `right` 改 `top-left`。 |
| `quote-lockup` 引用他人话 | `side: left` | 本期 card-5 大负偏移落到中左。 |
| `punch-pill` / `blur-text` 金句·情绪 | `bottom`（字幕上方） | 同 default；本期仅做小幅左/上微调，未推翻。 |
| 通用 | **整体往左半区收** | 人物在画面右/中右时不压人；right 锚定的卡也往中间/左拉。学方向不学绝对值（offsetX 绝对值是逐卡拖距，不泛化）。 |

**同屏错开 / 不与章节卡重侧**：同 default（left / right / bottom 交替，相邻不连续同侧）。

## 偏好·常驻层·字幕

- `caption-track` 的 `scale`：**0.85**（默认 1.0 占画面过多，本期被缩小）。

## 偏好·卡片尺寸（content card scale）

内容卡默认放大：AI 初编留 1.0 偏小，本期（良品计划开源口播 2026-10-10；已确认）多数内容卡被放大到 1.3–1.5——chapter-bar 1.35、pin-board 1.45/1.6/1.75、checklist 1.4、punch-pill 1.55、entity-chips 1.2、slab-punch-title 也上调。
以后**内容卡默认 scale ≈ 1.3–1.5**（要点钉板 pin-board 可到 1.6–1.75；个别大图卡按版面到 1.75），不再留给它 1.0。`caption-track` 仍维持 0.85 不变（见上）。
