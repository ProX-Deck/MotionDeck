# 我的偏好（默认取值表）

> overlay-generator 的默认偏好。缺失 `我的偏好.md` 时由本文件兜底（中性默认）。
> 用户可复制本文件为 `我的偏好.md` 覆盖其中的任何一项。
> 本文件只定义【偏好·落位】；其余偏好小节（密度与节奏 / 多样性 / 颜色·色义约定 / 文字量 / 让位与压暗）未定义时，按 SKILL.md 既定回退规则执行。

## 偏好·落位（口播人像默认主轴）

**前提**：人物居中、全程在画面里（口播 / 访谈 / 讲稿类）。
**硬约束（SKILL 已定）**：卡不许盖脸。

**主轴 = 左右分流，不要 center。**

| 卡型 / 场景 | 落位 | 说明 |
|---|---|---|
| `chapter-title-card`（full 人缩小窗） | `center` | 本就替换人物，是设计意图，保留 |
| `versus-card` | `center`（组件硬编码，无可调 position） | 全帧对撞；要避脸只能改组件或换卡型，不要假装能调 |
| `impact-open-title` / `type-shift` / `outline-box-title` / `keyword-pop-highlight` / `strike-and-replace` / `speed-slab-title` / `slab-punch-title` 等论点·标题·强调类 | `left` / `right` **交替** | still 卡，center 必盖脸；相邻卡不重侧 |
| `punch-pill` / `blur-text` 金句·情绪·设问 | `bottom`（字幕上方） | still 卡，bottom 不盖脸 |
| `quote-lockup` 引用他人话 | `side: left` / `right` | 用 `side` 参数，不是 `position` |
| `pin-board` 要点钉板（half 人下沉） | `left` / `right` | 落角落陪跑整段 |
| `checklist` / `step-timeline` / `term-card` 等列表·步骤·术语 | `left` / `right` | 同上，still/half 都走侧 |

**同屏错开**：同一时刻至多一张占某落位；left / right / bottom 交替使用，相邻内容卡不连续同侧。
**不与章节卡重侧**：常驻章节卡（step-timeline / punch-pill 角落版）占一侧时，同段内容卡用另一侧或 bottom。
